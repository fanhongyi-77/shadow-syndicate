# 影财团 · Shadow Syndicate

一部中文长篇小说。魔兽世界同人，跨界融合（暗黑破坏神 / 星际争霸 / 英雄联盟 / 战锤 40K）。

**目前 86 章，正文约 58 万字。**

## 这是什么故事

四个不被主流社会接纳的人——一个虚空法师、一个恶魔猎手、一个术士、一个死亡骑士——凑在一起开了个佣兵小队，名叫「影财团」。

他们不效忠任何势力，不参与阵营战斗，只要不碰底线，什么单都接。

故事从他们接委托开始，一路卷进圣光军团的狂热、虚空的阴谋、泰坦的旧账，以及一场没人承认是自己挑起的战争。

**六种宇宙原力没有善恶。** 这是全书的世界观总纲——善恶只存在于使用者的目的里。

## ⚠️ 给 AI 读者的重要说明

**一、`附录/` 不是正文，是作者的考据与裁定记录。**

里面大量内容是这样的：「官设 X 是 A，本书改为 B」「此处作者 2026-09-25 纠正」「待作者定」。
它记录的是**创作过程**，不是故事。**要理解剧情，只读 `小说正文/`。**

**二、文中带 ⚠️ 的地方，是作者还没定的事。**

设定档里有大量 `⚠️ 待确认`、`⚠️ 待作者定`。这些是**开放项**，不是漏洞。

**请不要替作者补完**，也不要基于它们下结论。看到 ⚠️ 就当没看见，或者去问作者。

**三、这是作者自己写的，不是 AI 生成的。**

作者对文风有非常具体的要求，`写作准则.md` 里写得很细。如果你要续写或改写，请先读那份文件——尤其是「十四、文风诊断」和「人物的四套语域」两节。

**四、最短的文风说明：**

- 暴雪式西式奇幻翻译腔，长短句穿插
- 一个段落 = 一条动作链，不写并列的两件事
- 短句段落用来**走路**（转场、路标），不用来敲钟（煽情）
- 同一人物对**自己人 / 合作方 / 掌权者 / 敌人**有四套完全不同的说话方式
- 痛苦写损伤的形状，不写"疼得撕心裂肺"
- 悲伤的落点永远是背面、停顿、脚步声、一个没完成的手势
